Owner's guide · August 2026

MastGaane. The reels you scroll at night, as a playlist by morning.

A small program on this PC that scrolls your Instagram Reels feed every night, notices the Hindi film songs, ghazals and folk songs in it, identifies them, and keeps a playlist up to date on YouTube Music, Spotify and Apple Music.

Installed · 16 tests passing Scheduled daily 00:30 Local AI: Ollama qwen2.5:7b To do: Instagram login To do: YouTube Music headers

What it does

Instagram never tells you which reels you watched, so MastGaane watches with you: it opens its own Chrome window, scrolls the Reels feed the way a person would, and records what the feed serves. Because the browser is a real Chrome with a remembered login, Instagram sees ordinary browsing. The app never calls Instagram's servers itself; it only reads the data the page fetches on its own.

HarvestChrome scrolls ~150 reels, lingers on musical ones, records each reel and its tagged audio.
ResolveFinds the song: Instagram's tag → Shazam → lyrics + local AI. Then labels language and genre.
SyncApproved songs go to the YouTube Music playlist, Spotify (if enabled), and the Apple Music list.
ReportA morning summary in reports/ and the web page at localhost:8787.

Lingering longer on the musical reels has a side effect you will like: it nudges the Instagram algorithm toward more of them.

Finish the setup

Everything is installed; two accounts still need to be connected once. Both are done from PowerShell inside the project folder:

cd B:\youtubeProjects\Buzzcaf_Media\MastGaane
  1. Log in to Instagram — uv run mastgaane setup login

    A Chrome window opens using MastGaane's own profile (separate from your normal Chrome). Sign in, finish any two-factor prompt, and let it scroll three reels. The login is remembered from then on.

  2. Connect YouTube Music — uv run mastgaane setup ytmusic

    Open music.youtube.com signed in → press F12 → Network tab → type browse in the filter → click any POST request → right-click Request Headers → Copy value → paste into the terminal → Enter, then Ctrl+Z and Enter. This writes browser.json.

  3. Do one small test run while you watch

    uv run mastgaane harvest --max-reels 20 --capture then uv run mastgaane resolve and uv run mastgaane sync. Takes about five minutes and shows real songs flowing. The --capture flag saves Instagram's raw data so any parsing problem can be fixed quickly.

  4. Optional: Apple Music on the iPhone, Spotify, a smarter AI

    See the services section. None of these block the nightly run.

Every night at 00:30

A Windows scheduled task named MastGaane Nightly is registered and enabled. Next run: Monday 24 August 2026, 00:30. It runs mastgaane run-all: harvest → resolve → sync → report, about 30–40 minutes in total.

needs
The PC on and you logged in to Windows. A locked screen is fine; a signed-out session is not, because Chrome has to be visible to Instagram as a normal browser.
you will see
A Chrome window appear and scroll by itself for ~25 minutes. Leave it alone; use your normal Chrome if you need the browser.
log
reports\nightly.log — the full console output of each run.
summary
reports\2026-08-24.md and so on: songs kept, rejected (with reasons), reels that need a look.
if it missed a night
The task is set to run as soon as the PC is next available, and to retry once after ten minutes if it fails.
change the time
.\scripts\schedule_task.ps1 -At "01:00" re-registers it. Or use Task Scheduler → MastGaane Nightly.
Until Instagram is logged in, the nightly run opens Chrome, waits five minutes for a login, then gives up and still runs the rest of the pipeline on whatever is already in the database. Do step 1 above before tonight and it will work from the first night.

Only Hindi, ghazal, folk

Every song is labelled with the language it is sung in (captions are ignored — they are usually English) and a genre. Then two allow-lists in rules.yaml decide. Anything outside them is marked rejected with the reason, so nothing disappears silently.

allowed_languages: [hindi, urdu]          # ghazals are often Urdu, so both count
allowed_genres:    [film, ghazal, folk]   # add sufi, classical, devotional, indie to widen
always_keep_artists: [Jagjit Singh, Ghulam Ali, Arijit Singh, …]
always_skip_patterns: [meme, comedy, dialogue, remix, phonk, …]

How songs are identified

TierSourceConfidence
1Instagram's own music tag on the reel (most film songs)0.90
2Shazam fingerprint of a 25-second clip, for "original audio" reels and covers0.75
3Whisper transcribes the lyrics; the AI guesses the song from lyrics, caption and account≤ 0.70

Songs with confidence ≥ 0.80 that pass the rules are approved without asking; the rest wait on the Songs page. The same song served by five different reels becomes one entry with a seen ×5 count — a good sign the algorithm really wants you to hear it.

The AI runs on this PC

Song guessing and genre labelling use Ollama with qwen2.5:7b on the RTX 5060 Ti — about five seconds per song, nothing leaves the machine, no cost. The app starts Ollama itself if it is not running. Check it any time with uv run mastgaane llm --test.

  • Smarter local model (recommended, fits in 16 GB): ollama pull qwen2.5:14b and set LLM_MODEL=qwen2.5:14b in .env. The 7B model occasionally misjudges taste — it skipped Ranjha as "pop".
  • Claude as backup: put ANTHROPIC_API_KEY in .env. With LLM_FALLBACK=true it is used only when the local model is down or answers badly; LLM_PROVIDER=claude makes it primary (best at obscure ghazals from garbled lyrics).

YouTube Music · Spotify · Apple

YouTube Music — primary

After the one-time header setup, sync creates a private playlist MastGaane - Late Night and adds each approved song's best match. Re-running never duplicates.

Apple Music — from the iPhone, no developer account

  1. Start the page for the phone

    uv run mastgaane serve --lan on the PC. Allow it through Windows Firewall the first time.

  2. Open it on the iPhone (same Wi-Fi)

    http://192.168.1.9:8787/apple — tap Open on any song; it lands in Apple Music where + Add to Playlist is one tap away.

  3. Bulk import with a Shortcut (build once)

    Shortcuts app → + → Get Contents of URL http://192.168.1.9:8787/apple/import.txt → Split Text by New Lines → Repeat with Each: Search Music (Apple Music catalog, limit 1, term = Repeat Item) → Add to Playlist "MastGaane - Late Night". Run it whenever you want the Apple playlist refreshed.

If you ever join the Apple Developer Program, set APPLE_DEV_TOKEN, open /apple/auth once, and the playlist syncs automatically.

Spotify — only with Premium

Spotify's developer rules (March 2026) require a Premium account. Create an app at developer.spotify.com with redirect URI http://127.0.0.1:8788/callback, put the client ID and secret in .env, set SPOTIFY_ENABLED=true, run uv run mastgaane setup spotify. The Playlist page then gets a Play on my Spotify device button.

When something breaks

SymptomWhat to do
Reels are recorded but few have song namesInstagram changed its data format (happens every few weeks). Run harvest --max-reels 5 --capture and share the files in data\captures; it is usually a one-line fix in parse.py.
Instagram shows "suspicious activity"Run uv run mastgaane setup login, clear the prompt in the window, and lower MAX_REELS to ~60 in .env for a few days.
Chrome does not open / "did not open debug port"Check CHROME_PATH in .env. Port 9222 on this PC belongs to Adobe, so MastGaane uses 9555 — keep it that way.
Songs all land in "needs review"Ollama is probably not running: uv run mastgaane llm shows what is reachable.
Nothing happened last nightOpen reports\nightly.log. If empty, the PC was off or you were signed out of Windows. Run uv run mastgaane run-all by hand.
Phone cannot open the Apple pageUse serve --lan, same Wi-Fi, and allow Python through Windows Firewall (private networks).
