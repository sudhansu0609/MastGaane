iPhone: “Hey Siri, Mast Pehchano” (uses the iPhone's own Shazam)
  1. Run MastGaane so the phone can reach it: uv run mastgaane serve --lan (phone on the same Wi-Fi).
  2. Shortcuts app → + → add the Shazam action (search “Shazam”; it may be called Shazam It or Recognise Music).
  3. Add Get Contents of URL: URL {{ lan_url }}/api/listen/save, Method POST, Request Body JSON with three Text fields: title = Shazam result Title, artist = Artist, apple_url = Apple Music URL. Optional: play = now to hear it on the PC at once.
  4. Add Get Dictionary Value summary → Speak Text (or Show Result).
  5. Name the shortcut Mast Pehchano. Now “Hey Siri, Mast Pehchano” names the song and drops it into your collection.

The 📱 Record on phone button above also works from the phone's browser at {{ lan_url }}/listen — no Shortcut needed.
